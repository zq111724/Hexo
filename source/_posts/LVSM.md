## 1. 从三维重建到直接的新视角合成

给定若干幅稀疏的已知位姿图像，如何生成指定相机视角下的 RGB 图像？传统新视角合成（Novel View Synthesis，NVS）的一个典型思路是先获得场景表示，再通过渲染得到目标图像。无论是逐场景优化的 NeRF、3D Gaussian Splatting，还是前馈预测三维表示的大型重建模型（Large Reconstruction Model，LRM），都对场景如何表示、图像如何形成作出了某些预先规定。

LVSM（Large View Synthesis Model）提出另一种选择：如果任务本身仅要求预测目标图像，是否可以不显式构造三维场景，而让一个足够强的 Transformer 直接从大量多视图数据中学习合成映射？

### 1.1 两种不同层级的三维归纳偏置

作者将相关方法使用的三维归纳偏置（3D inductive bias）区分为两类：

- **表示层归纳偏置**：规定场景必须由体密度、辐射场、高斯原语、网格等形式表示，并使用相应的渲染机制生成图像。
- **网络层归纳偏置**：通过极线投影、平面扫描、显式特征匹配等几何操作来组织不同视角之间的信息交换。

这些约束有其价值：当观测不足时，它们提供明确的几何结构或成像关系。但是，固定表示和信息流也可能限制模型对复杂结构、非典型外观和视角相关效应的表达。已有大型重建模型已经减少了一部分网络层约束，却通常保留三维表示与渲染。LVSM希望进一步放开这一限制。

需要明确：**减少三维归纳偏置并不等于没有几何条件。** LVSM仍需要已知的相机内参和外参，并利用这些参数计算每个像素对应的空间射线。它取消的是预设的三维场景形式和几何渲染操作，而不是相机条件。输出是目标RGB，不是深度、点云或高斯集合。

这种不依赖显式三维表示的路线并非 LVSM 首创。Scene Representation Transformers（SRT）已经通过 Transformer 学习潜在场景表示，再由目标相机条件生成图像，与 LVSM ED 的高层思路相似。按原文 §2、§4.4，LVSM ED 的区别在于采用线性 Patchify、固定长度场景 latent 及双向 Self-Attention，而 SRT 使用 CNN tokenizer、随输入视图数线性增长的 latent 序列及纯 Cross-Attention 解码器。LVSM DO 则进一步取消独立的中间场景表示。

### 1.2 核心技术逻辑：表示压缩还是直接条件预测？

![Figure 2 — 两种LVSM模型架构](LVSM/Figures/Figure_02.jpg)

Figure 2（原文 p.4）给出了两条路线。两者先把输入图像与射线、目标相机射线转成 token，再通过全自注意力预测目标图像的 patch。区别在于是否保留一个目标无关的独立场景表示：

| 架构 | 信息流 | 设计取舍 |
|---|---|---|
| Encoder-Decoder（ED） | 多视图输入 → 固定长度场景latent → 与目标射线联合解码 | 场景表示可以复用，适合同一场景反复渲染；固定长度可能限制信息保留 |
| Decoder-Only（DO） | 多视图输入与目标射线 → 单流Transformer → 目标RGB | 目标条件自第一层参与信息聚合；不经过独立场景瓶颈，但每次解码的序列长度随输入视图数量增长 |

训练时两者使用同一类目标图像监督。由此形成贯穿论文的假设：更加自由的单流信息交换可能提高合成质量及新增观测利用能力，而固定场景表示可以换来更高的多目标解码吞吐。主比较、结构消融与视图数实验分别检验这些主张，并非用RGB指标证明隐式三维几何已被准确恢复。

## 2. 统一的输入、输出与训练目标

### 2.1 将相机条件和图像变成 token

设有 $N$ 幅图像及相机参数：

$$\{(I_i,E_i,K_i)\}_{i=1}^{N},\quad I_i\in\mathbb R^{H\times W\times3}.$$

$E_i$、$K_i$ 分别为外参和内参，目标相机参数为 $E^t,K^t$。模型需要预测 $\hat I^t$。

给定相机，每个像素对应一条空间射线。LVSM用六维 Plücker ray embedding（普吕克射线嵌入）描述该射线。作为补充理解，若采用世界到相机外参 $X_c=RX_w+t$，齐次像素为 $\tilde u$，相机中心及单位射线方向可以写成：

$$o=-R^\top t,\qquad d_r=\frac{R^\top K^{-1}\tilde u}{\|R^\top K^{-1}\tilde u\|}.$$

射线的 Plücker 矩为 $m=o\times d_r$，六维表示由 $d_r$ 与 $m$ 组成。上述为教学性的常用坐标约定，原文没有指定六维排列和完整实现细节。射线确定的是空间直线，而不是射线上物体的深度。因此，即使相机已知，遮挡、匹配与未知几何仍需要从观测及学习先验推断。

实现上，物体级和场景级实验的视图选择与相机位姿归一化均沿用 GS-LRM（原文 A.2，p.18）。原文未详细展开归一化算法；上述射线推导用于解释统一坐标约定下的几何关系，不代表完整的实际预处理流程。

将 RGB 和射线分别切成不重叠的 $p\times p$ patch。第 $i$ 幅输入图像的第 $j$ 个 patch 为 $I_{ij}\in\mathbb R^{p\times p\times3}$、$P_{ij}\in\mathbb R^{p\times p\times6}$；拼接并展平后，得到 $9p^2$ 维向量，再通过线性层映射为 $d$ 维 token（原文 Eq.1）：

$$x_{ij}=\operatorname{Linear}_{input}([I_{ij},P_{ij}])\in\mathbb R^d.$$

对于目标视图，不提供RGB，只用目标相机计算六维射线 $P^t$，按同样方式得到目标查询 token（Eq.2）：

$$q_j=\operatorname{Linear}_{target}(P^t_j)\in\mathbb R^d.$$

输入与目标分别形成长度为 $l_x=NHW/p^2$、$l_q=HW/p^2$ 的序列。默认 $p=8,d=768$；当分辨率为256×256、输入4幅时，输入序列4096个 token，目标序列1024个 token。注意目标 query token 是目标射线的嵌入，不等同于 Transformer 内部注意力矩阵 Q 中的查询向量。

### 2.2 直接预测 RGB 而不是三维渲染参数

原文 Eq.3 将整体映射写为：

$$y_1,\ldots,y_{l_q}=M(q_1,\ldots,q_{l_q}\mid x_1,\ldots,x_{l_x}).$$

$M$ 表示以下两种 Transformer 架构之一，每个输出 $y_j$ 是经过多层交互后的目标 patch 特征。输出头将其映射到 $3p^2$ 个 RGB 标量（Eq.4；Fig.8还显示输出前的 LayerNorm）：

$$\hat I^t_j=\operatorname{Sigmoid}(\operatorname{Linear}_{out}(y_j))\in\mathbb R^{3p^2}.$$

$p=8$ 时，一个 token 预测64个像素的192个RGB分量。所有 patch 按原图位置重组为目标图像。不需要先估计显式深度、密度或高斯属性，再执行沿射线积分。

监督信号为真实目标图像 $I^t$，损失包含像素误差和感知损失（Eq.5）：

$$\mathcal L=\operatorname{MSE}(\hat I^t,I^t)+\lambda\operatorname{Perceptual}(\hat I^t,I^t).$$

物体实验 $\lambda=1$，场景实验 $\lambda=0.5$（A.2）。前者约束颜色数值，后者补充学习特征层面的相似性；原文未展开感知网络的具体层配置。真实目标RGB只用于损失，不作为目标查询输入。该训练关系解释了模型为何能够学习NVS，也限定了其证据：并没有独立的几何监督或显式场景参数恢复目标。

## 3. 两种 Transformer 如何利用观测信息？

![Figure 8 — 详细张量形状、层数与自注意力块](LVSM/Figures/Figure_08.jpg)

Figure 8（p.19）展开了网络。两者采用纯自注意力 Transformer，默认总计24层。论文所称的 Decoder-Only 不是语言模型式的因果自回归 decoder：输入和目标 token 均可以参与双向注意，目标图中的各 patch 在网络中联合更新。

### 3.1 Encoder-Decoder：学习目标无关的场景 latent

将输入序列记为 $x\in\mathbb R^{l_x\times d}$。另外定义固定长度的可学习 token 序列 $e\in\mathbb R^{l\times d}$，默认 $l=3072$。$e$ 是所有场景共享的网络参数，而不是当前场景已经估计出的表示。

Encoder 接收 $x$ 与 $e$ 的拼接序列，经12层全自注意力，得到更新后的输入特征 $x'$ 和场景 latent $z$（原文 Eq.6 的紧凑记法）：

$$[x',z]=\operatorname{Transformer}_{Enc}(x,e).$$

丢弃 $x'$，保留 $z\in\mathbb R^{l\times d}$。由于 Encoder 未接收目标查询 $q$，对于固定输入观测，$z$ 与目标相机无关。它可以作为同一场景的共享上下文。

随后将 $z$ 与目标射线 token $q$ 拼接，经过12层 Decoder（Eq.7）：

$$[z',y]=\operatorname{Transformer}_{Dec}(z,q).$$

此处 $z'$ 是经过目标条件更新后的 latent，不再是目标无关的表示；网络丢弃它，仅从目标位置的 $y$ 回归RGB。与纯交叉注意力不同，Decoder 内部的 latent 可以读取目标 token，目标之间也可以交换信息。

该结构将整个映射分解为 $M(q\mid x)=D(q,Z(x))$。对同一场景的多个目标，只需计算一次 $Z(x)$，但所有后续目标使用的信息都要经过固定长度的 $Z$。如果场景摘要没有保留某个目标所需的观测细节，解码器便无法从原输入重新获取该细节。这是潜在的信息瓶颈，并非证明3072个latent在所有情况下必然不足。

### 3.2 Decoder-Only：让目标直接访问观测上下文

DO 进一步取消独立场景 latent。它直接将输入序列与目标查询拼接，经24层全自注意力（Eq.8）：

$$[x',y]=\operatorname{Transformer}_{Dec-only}(x,q).$$

从第一层起，目标条件可以影响输入 token 的更新，目标 token 也能在不同层反复读取输入上下文。最终舍弃输入位置的 $x'$，对目标位置的 $y$ 回归RGB。

DO 仍然具有多层隐藏特征；所谓消除中间场景表示，是指没有独立、目标无关、固定长度的场景摘要。不同目标相机进入网络会改变上下文，因此不能直接像 ED 一样缓存最终的场景 latent。

从结构上看，改变输入视图数量只需相应改变输入 token 序列长度（保持图像分辨率与 patch 尺寸不变）。标准 Transformer 的注意力投影和逐 token MLP 在序列位置间共享参数，其权重形状不依赖序列长度。因此，DO 可直接处理不同长度的输入上下文，ED 的 Encoder 也可接收可变数量的输入 token，再聚合到固定数量的场景 latent。这是结构层面的兼容性，并不保证训练分布之外的泛化质量；两者能否有效利用新增观测，仍需由 §5.3 的输入数量实验检验。

### 3.3 多层双向交互为什么重要？

![Figure 9 — 四种注意力可见性掩码](LVSM/Figures/Figure_09.jpg)

Fig.9（p.20）给出不同注意力设计。以 L 表示 latent（ED）或输入（DO），T 表示目标 patch；图中行表示正在更新的查询位置，列表示可读取的键/值位置。

| 设计 | L读L | L读T | T读L | T读T |
|---|---|---|---|---|
| 完整双向 | ✓ | ✓ | ✓ | ✓ |
| Per-patch prediction | ✓ | — | ✓ | — |
| Pure cross-attention | — | — | ✓ | — |
| 不更新latent | — | — | ✓ | ✓ |

目标 patch 不仅可以读取观测，还能相互交换上下文。例如，一个局部区域的边缘或颜色估计可以借助邻近 patch 的特征；目标信息也可反馈到 latent，再由其它目标 patch 读取。由于存在多个 Transformer 层，这种交换并不限于一次查询。图中的灰色整行表示对应分组不进行注意更新，并非对全负无穷 logits 强行执行 softmax。

这里的目标 patch 均来自**同一目标图像**。不能将这个机制理解成多个新视图之间的联合扩散或跨帧一致性模块。原文 A.6 说明推理时各目标图像独立生成。

### 3.4 信息瓶颈与算术成本的权衡

标准 dense self-attention 在长度为 $L$、宽度为 $d$ 的序列上形成 $L\times L$ 的注意力打分矩阵，算术复杂度含 $O(L^2d)$ 项（投影和MLP另有约 $O(Ld^2)$ 项）。Fig.8中的QKNorm改善训练稳定性，并不消除序列二次增长；FlashAttention可以降低中间显存和访存成本，但不会将全注意力的理论打分数变成线性。

ED 的编码长度为 $l_x+l$，解码长度为 $l+l_q$；DO 每个目标处理 $l_x+l_q$。以256分辨率、4输入、3072 latent为例：ED编码7168个 token，解码4096；DO为5120。若目标数为 $M$，只以每层 $L^2$ 作为注意力算术量代理，则 ED 和 DO 分别约为

$$12(7168)^2+12M(4096)^2,\qquad24M(5120)^2.$$

这是补充计算，不是论文实测FLOPs。单目标时编码可能使ED总计算更大；目标增加时，固定表示的复用逐渐体现优势。若输入增加到16幅，DO序列变成17408，而ED每目标解码仍为4096。实际速度还取决于投影、内存、设备和批处理，因此应与真实FPS实验结合，而不能只凭上述复杂度预测具体吞吐。

## 4. 训练与推理条件

论文在物体和场景数据上分别训练。物体模型使用 Objaverse 约73万对象，每对象渲染32个随机视图；在 GSO（1099对象）和 ABO（1000对象）测试，4幅输入、10幅目标。场景模型使用 RealEstate10K，约8万片段来自1万段YouTube视频，采用pixelSplat的训练/测试划分。训练时物体默认4输入8目标，场景2输入6目标。主物体实验包含256和512两种设置，主场景比较为256分辨率。

默认模型宽度768、24层，ED采用12+12层、3072 latent。主配置64 A100、每卡batch8，总batch512；256分辨率训练，随后可微调到512。作者在§4.2指出普通 Transformer 训练会因梯度爆炸而崩溃，使用 QKNorm、梯度裁剪1、跳过范数超过5的优化步稳定训练；同时使用 FlashAttention-v2、梯度检查点与bf16。完整训练参数见完整精读报告。

推理无需每场景优化权重：给定新场景的带位姿观测和目标相机，ED先计算场景latent再解码，DO直接联合处理输入及目标token。官方代码仓库标明公开代码是重新实现版本，不应直接将其视作Adobe内部原始训练代码。

## 5. 实验证据：质量、结构与可扩展性

### 5.1 主比较：取消显式三维表示是否牺牲RGB质量？

Table 1（p.6）中的 Decoder-Only 相对于 GS-LRM 的 PSNR 对比如下。物体评估匹配输入和渲染分辨率，场景评估使用pixelSplat的256验证集。

| 数据集与分辨率 | GS-LRM | ED | DO | DO增益（dB） |
|---|---:|---:|---:|---:|
| ABO 512 | 29.09 | 29.81 | 32.10 | +3.01 |
| GSO 512 | 30.52 | 29.32 | 32.36 | +1.84 |
| ABO 256 | 28.98 | 30.35 | 32.47 | +3.49 |
| GSO 256 | 29.59 | 29.19 | 31.71 | +2.12 |
| RealEstate10K 256 | 28.10 | 28.58 | 29.67 | +1.57 |

注意，原文§4.3将 GSO 512 的提升写为2.8 dB，但表中32.36−30.52=1.84 dB；这里明确采用表格复算，保留原文不一致。DO在该表各组的PSNR、SSIM和LPIPS均领先，ED并非全部指标占优，例如GSO 512三指标低于GS-LRM。RealEstate10K DO为29.67 dB、0.906 SSIM、0.098 LPIPS，GS-LRM为28.10、0.892、0.114。

![Figure 3 — 512分辨率物体定性比较](LVSM/Figures/Figure_03.jpg)

Fig.3展示薄结构、小孔和高频纹理：DO在多组选例中更接近GT，能够减少浮状伪影、模糊与结构错误。

![Figure 4 — 场景级定性比较](LVSM/Figures/Figure_04.jpg)

Fig.4对比室内场景，LVSM在反射、栏杆、桌面纹理等局部区域具有视觉优势。RGB外观与真实图更一致，是有意义的NVS证据，但这些实验没有直接测量物体的三维拓扑、深度或材质参数。

### 5.2 结构消融：全双向信息流是否必要？

Table 3（p.9）将 Fig.9 的掩码干预用于具体实验。 其中 CNN tokenizer 与 Pure Cross-Attention 解码器是原文 §4.4 借鉴 SRT 的两种组件级替代设计，用于检验 LVSM 自身的线性 Patchify 和全双向注意力选择，而非对完整 SRT 的复现实验。物体ED使用32 GPU、batch256、8目标；场景DO采用原主训练设置。以下数值不可与Table 2的小规模资源实验混用。

| GSO（ED） | PSNR↑ | SSIM↑ | LPIPS↓ |
|---|---:|---:|---:|
| 完整ED |28.07|.920|.053|
| CNN tokenizer |27.59|.914|.052|
| 不更新latent |26.61|.903|.061|
| Per-patch prediction |26.27|.897|.072|
| Pure cross-attention |24.60|.876|.085|

关闭 latent 更新下降1.46 dB，限制逐patch预测下降1.80 dB，同时取消两类交流的纯cross设计下降3.47 dB。CNN tokenizer 的LPIPS略好（.052 vs .053）是例外，不能说线性token化在所有指标上都占优。场景DO同样从29.67下降到28.98 dB（−0.69），SSIM从.906降为.897，LPIPS从.098升为.103。这些结果支持完整自注意力设计，但 per-patch 掩码同时改变目标反馈与目标之间的交互，不能精确拆分每条信息路径的因果贡献。

Table 2（同页）在8 GPU、总batch64下比较模型规模。ED总173M参数固定，6+18层在GSO/RE10K得到26.48/28.32 dB，18+6层只有24.74/26.80；分配更多解码层有利。DO从6层43M增加到24层171M，GSO从24.15上升到27.04，场景从27.62到28.89。近同参数的DO24优于ED6+18，但不同序列长度意味着并未匹配全部训练计算量；作者关于编码压缩误差的解释仍是有待验证的假设。

### 5.3 训练时只使用4视图，测试时增加观测会怎样？

![Figure 5 — 不同输入数量的零样本泛化](LVSM/Figures/Figure_05.jpg)

Fig.5（p.10）在GSO测试1、2、4、6、8、12、16幅输入，所有模型仅用4输入训练。DO随新增视图继续提升，16输入约35.5 dB；ED和GS-LRM在约6–8视图后趋于饱和甚至下降（图读近似）。这不仅说明 ED 和 DO 在结构上均可接受不同数量的输入，也为训练之外的输入数量泛化提供了实际证据：在该测试范围内，DO 对新增观测的利用效果更好。结果支持直接利用观测上下文的策略；固定场景表示可能限制新增信息的保留，但不能排除训练分布偏移、融合难度等替代解释。这里的 zero-shot 特指测试输入数量变化，而非任意领域泛化。

![Figure 6 — 输入视图数与解码FPS](LVSM/Figures/Figure_06.jpg)

Fig.6在物体256设置中测量**解码**速度。ED接近90 FPS；DO约从单视图97 FPS降至4输入35 FPS、8输入16 FPS、16输入6 FPS（图读近似）。这与序列长度分析一致，但 ED 一次性编码开销不计在图6内。单输入时DO甚至可能更快，不能断言ED在所有端到端设置都具有速度优势。

### 5.4 较小模型能否在学术算力下训练？

§4.3另报告 RE10K 的较小DO模型：单A100 80GB、6层、batch64训练7天，得到27.66 dB、.870、.129；相较MVSplat的26.39、.869、.128，PSNR领先1.27 dB，但LPIPS略差。双GPU、12层、batch64训练7天，得到28.56 dB、.889、.112；相较GS-LRM，PSNR和LPIPS更好，SSIM略低。这说明小规模模型有竞争力，不代表64卡主模型的完整性能可由单卡直接复现。

## 6. 能力边界与研究启发

LVSM是确定性前馈回归模型。A.6说明作者在项目视频中观察到：即使各目标图像独立生成，已观测区域仍可以保持较好的跨视图一致性。与概率生成模型不同，固定输入和目标条件不会产生随机采样变化。但 A.7 同时指出未观测区域经常出现噪声、闪烁与固定图案；作者建议将生成方法与LVSM结合。此外，在512×512训练后测试512×960输入，中心区域较好、横向边界模糊。作者推测与中心裁剪训练导致的长边射线分布差异有关。

从推断角度看，假设两个场景在所有输入视角中完全一致，却在遮挡背面有不同内容，那么相同输入条件的确定性网络无法保证两者的背面都正确。减少三维表示约束可以提升网络的表达自由度，却不消除观测不足引起的不可辨识性。用生成先验补全未知内容也不等于恢复真实内容；如需可信恢复，必须另行评价观测支持范围、真实几何与不确定性。

由此产生几个值得继续检验的技术问题：固定latent的饱和究竟来自容量限制还是训练分布偏移？是否可以按新增观测的有效覆盖而非数量自适应选择上下文，在保持目标条件交换的同时降低长序列代价？对于观测不足的区域，能否提供经验证的不确定性而不是仅输出一张合理图像？这些是由本文现象引出的研究假设，不是作者已完成的实验或已经验证的新颖研究问题。

LVSM的贡献在于展示了**不依赖预设显式三维表示的高质量、可扩展NVS路线**，并通过ED与DO的对比揭示场景信息压缩、目标条件化和解码计算之间的取舍。它没有证明三维归纳偏置普遍无用，也没有直接解决三维真实性、未知相机或不可见区域的可靠推断。
