DiffusionGS：将三维高斯融入扩散去噪器的单阶段图像到三维生成与重建

阅读完整精读报告

论文版本： arXiv:2411.14384v6（2026-11-18）；核验时为最新版（2026-11-27）。

官方资源： arXiv | PDF | Project Page | Code | Model | Dataset | Demo 1 | Demo 2

1. 研究问题：生成的新视图必须对应同一个三维世界

DiffusionGS 研究从单张 RGB 图像与相对相机条件出发，生成一个可用于新视图合成（Novel View Synthesis, NVS）的显式三维高斯场景。它既面向物体生成，也面向室内外场景重建。

困难在于，一张图像只能观察到部分表面。两种不同深度或背面形状完全可能产生相同的条件图像；生成模型可以借助训练先验补全不可见区域，却不能凭空获得新的真实观测。

现有二维扩散方法可以先生成多个目标视图，再利用这些图像拟合一个三维模型。问题是，单独看起来合理的几张图片可能对同一个遮挡后结构给出矛盾解释。例如，一个视角生成了完整窗户，另一个视角却改变了窗户的位置。事后拟合高斯只能折中解释这些冲突，产生模糊、错位或不可靠的深度。另一条已经存在的路线是使用二维渲染损失训练三维扩散模型，例如单阶段方法 DMV3D。它不是在二维生成结束后才构建三维；但这类方法主要依赖三平面 NeRF，受到三平面分辨率和体渲染开销的限制（原论文 §2.1、§4.1）。

本文并非首次提出三维扩散或单阶段三维生成。其核心创新在于：将像素对齐的显式三维高斯融入每个扩散去噪时间步，以共享高斯集合的可微光栅化结果推进下一步扩散。 相比先生成、后构建三维的路线，它把三维一致性约束前移到生成过程；相比已有的三平面 NeRF 三维扩散，它改变了三维表示及渲染方式，旨在降低渲染开销并支持更大的场景范围。

2. 核心框架：将 3DGS 融入去噪器

Figure 4(a) 描述数据选择，(b) 描述一次去噪的完整信息流。训练时从同一对象或场景选择一张干净条件图、NN 张真实目标图（用于加噪并提供去噪监督），以及 MM 张额外真实监督新视图。只有条件图和噪声视图及其相机条件进入去噪器；MM 张新视图及其相机用于额外渲染监督，不是额外推理输入。

推理时只有一张真实条件图。 模型同时需要条件图与 NN 个生成目标视角的相机条件（相对位姿及相应射线信息）；目标视角的图像内容从随机噪声开始生成，而非来自额外相机拍摄。因此这是相机条件已知的单图生成与重建，不是无位姿重建。

核心闭环由三个操作构成：

  1. 预测三维候选。 带噪视图、干净条件图、射线坐标和时间步共同进入 Transformer，经高斯解码器输出一组像素对齐的 3D Gaussian Splatting（3DGS）参数。
  2. 从同一候选渲染多视图。 不同相机渲染共享高斯集合，得到对应的干净图像预测。训练用真实多视图图像约束这一过程，无需高斯真值标签。
  3. 推进扩散。 将渲染出的干净图像用于下一个时间步采样，重复直至获得最终高斯集合。推理使用 30-step DDIM，因此 single-stage（单阶段）不是 single-step（单步）。

从研究逻辑看，共享三维表示是生成过程的结构约束；从模型信息流看，扩散状态始终是多视图图像，而非直接加噪的高斯参数；从训练监督看，真实多视图通过可微渲染将像素与感知损失传回三维去噪器。三个关系不能混为一谈。

3. 每一步如何预测并渲染三维高斯？

3.1 扩散在图像域，去噪预测在三维域

论文将第 ii 张干净目标图记为 x0(i)x_0^{(i)}，时间步为 tt，累计噪声调度为 α‾t\bar\alpha_t。前向加噪的原式（Eq. 1）为

xt(i)=α‾tx0(i)+1−α‾tϵt(i),ϵt(i)∼𝒩(0,I).x_t^{(i)}=\bar\alpha_t x_0^{(i)}+\sqrt{1-\bar\alpha_t}\epsilon_t^{(i)},\qquad \epsilon_t^{(i)}\sim\mathcal N(0,I).

这里保留论文原式。标准 DDPM 的信号系数通常是 α‾t\sqrt{\bar\alpha_t}，而本文 Eq. (1) 及后面的 Eq. (8) 写作 α‾t\bar\alpha_t，与 p.3 给出的 DDPM 分布均值存在不一致。实际实现采用何种系数，不能仅凭论文确定。

不同于直接预测噪声的去噪器，DiffusionGS 输出干净的三维候选（Eq. 2）：

𝒢θ(𝒳t∣xcon,vcon,t,𝒱)={Gt(k)(μt(k),Σt(k),αt(k),ct(k))}k=1Ng.\mathcal G_\theta(\mathcal X_t\mid x_{con},v_{con},t,\mathcal V)=\{G_t^{(k)}(\mu_t^{(k)},\Sigma_t^{(k)},\alpha_t^{(k)},c_t^{(k)})\}_{k=1}^{N_g}.

𝒳t\mathcal X_t 是 NN 张噪声图；xconx_{con} 是唯一干净条件图；vconv_{con} 与 𝒱\mathcal V 是对应的每像素六维相机射线坐标；每个高斯含中心 μ\mu、协方差 Σ\Sigma、不透明度 α\alpha 和 RGB 颜色 cc。

3.2 像素对齐高斯：让三维候选具有固定输出形状

普通三维高斯场景的点数不固定。为了让网络能够直接回归一组高斯，本文将每张输入图像的每个像素与一个高斯候选关联，因此 Ng=(N+1)HWN_g=(N+1)HW。

给定像素对应射线原点 o(k)o^{(k)} 和方向 d(k)d^{(k)}，网络预测沿射线的距离权重 wt(k)w_t^{(k)}，从而得到中心：

μt(k)=o(k)+ut(k)d(k),\mu_t^{(k)}=o^{(k)}+u_t^{(k)}d^{(k)}, ut(k)=wt(k)unear+(1−wt(k))ufar.u_t^{(k)}=w_t^{(k)}u_{near}+(1-w_t^{(k)})u_{far}.\tag{3}

若方向归一化，uu 是沿射线的距离；若 ww 被限制在 [0,1][0,1]，则它在近远界之间插值。论文没有明确权重的具体激活函数。将中心限制在射线上，利用了已知相机的几何关系，而不用让网络从整个三维空间盲目回归位置。但多视图中同一表面可以对应多个候选，固定点数不是几何正确性的保证。

输入端将 RGB 与六通道射线图拼接为九通道特征，再进行 patchify、线性映射和位置嵌入。Transformer 主干由自注意力和 MLP 等模块组成，通过跨视图 token 交互汇聚信息；时间嵌入利用自适应层归一化（AdaLN）调节主干和解码器。解码器把 token 还原为 H×W×14H\times W\times14 的高斯参数图，并从中提取距离权重、旋转、尺度、不透明度和颜色。论文未逐一给出14通道分配，不能自行补为确定的实现细节。

3.3 同一三维表示提供多个干净图像预测

可微光栅化函数 FrF_r 以相机内外参为条件，把同一高斯集合渲染为每个视角的干净图像（Eq. 4）：

x̂(0,t)(i)=Fr(Mext(i),Mint(i),𝒢θ).\hat x_{(0,t)}^{(i)}=F_r(M_{ext}^{(i)},M_{int}^{(i)},\mathcal G_\theta).

这里省略 𝒢θ\mathcal G_\theta 的输入参数，但它与 Eq. (2) 相同。在渲染过程中，三维高斯的世界系协方差经视图变换 WW 和投影雅可比 JJ 变换（Eq. 5）：

Σ′=JWΣWTJT.\Sigma'=JW\Sigma W^TJ^T.

直观上，若世界系点偏移为 δX\delta X，投影局部近似为 δy≈JWδX\delta y\approx JW\delta X，故协方差按上式传播。取投影协方差的二维子块，可以得到屏幕空间的高斯形状；光栅化按照投影覆盖分配 tile，并按视空间深度排序。

第 (m,n)(m,n) 个像素的颜色由覆盖它的有序高斯做前向 alpha 混合（Eq. 6）：

x̂(0,t)(i)(m,n)=∑j∈𝒩ct(j)σt(j)∏l=1j−1(1−σt(l)).\hat x_{(0,t)}^{(i)}(m,n)=\sum_{j\in\mathcal N}c_t^{(j)}\sigma_t^{(j)}\prod_{l=1}^{j-1}(1-\sigma_t^{(l)}).

𝒩\mathcal N 表示覆盖像素的有序高斯集合，σ\sigma 为高斯核响应与不透明度构成的有效 alpha，前方乘积为剩余透射率。当前点不透明时，它后面的点便无法贡献颜色。这样不同视角的可见性、遮挡和图像内容都由共同三维表示决定。

训练中的去噪损失由像素 L2 与 VGG-19 感知损失组成（Eq. 7）：

ℒde=ℒ2(𝒳̂(0,t),𝒳0)+λℒVGG(𝒳̂(0,t),𝒳0).\mathcal L_{de}=\mathcal L_2(\hat{\mathcal X}_{(0,t)},\mathcal X_0)+\lambda\mathcal L_{VGG}(\hat{\mathcal X}_{(0,t)},\mathcal X_0).

对额外 MM 个监督相机同样构造 ℒnv\mathcal L_{nv}。这使网络不能仅通过拟合当前噪声视角对应的图像来获得低损失，还需解释其他真实视图。由于渲染可微，图像误差可以反传至三维高斯参数和去噪器。需要注意，仅有 RGB 监督仍可能产生能解释图像但与真实结构不同的高斯。

3.4 推理：三维渲染与图像采样交替

推理先给定唯一干净条件图及其相机条件，并给定 NN 个生成目标视角的相机条件。在 t=Tt=T 为这些目标视角初始化 NN 张标准正态噪声图；后续时间步始终以同一干净条件图为条件，更新的是这组生成视图的图像状态。将每步渲染出的 x̂(0,t)\hat x_{(0,t)} 用于下一时间步，论文给出（Eq. 8 原式）：

xt−1(i)=α‾t−1x̂(0,t)(i)+1−α‾t−1ϵt−1(i).x_{t-1}^{(i)}=\bar\alpha_{t-1}\hat x_{(0,t)}^{(i)}+\sqrt{1-\bar\alpha_{t-1}}\epsilon_{t-1}^{(i)}.

实际采样报告使用30步 DDIM 跳过部分时间步，论文没有完整列出 DDIM 的更新参数。标准确定性 DDIM 会从当前状态和干净预测估计噪声并用于跳步；上式本身不等同于完整的确定性 DDIM 更新。最终在 t=0t=0 取 Eq. (2) 的高斯集合，之后可以用常规高斯光栅化在指定的新相机下渲染，不需要额外每场景三维拟合。这里应区分扩散过程中参与更新的 NN 个目标视角与最终三维表示的评估视角。原论文 §4 规定每个评估实例包含1张输入图和10张测试图，但未据此给出 NN 的具体配置，不能将两者等同。推理过程中生成的多视图是模型对未观测内容的推断，不是新增真实观测。

4. 为什么需要场景与物体混合训练？

对象级数据通常将对象归一化到有限中心区域，相机围绕对象旋转；场景级数据则包括密集背景、宽深度范围以及前进、后退和横移轨迹。作者指出，大量对象数据来自合成资产，而场景训练数据数量相对较少。直接混合可能产生伪影或不收敛。本文在共享主干之外进行以下适配。

4.1 控制训练视角分布

作者对相机位置和朝向分别设置角度约束。设 cc、dd、nn 分别代表条件、噪声和额外监督新视角，位置角约束为（Eq. 9）

θcd(i)≤θ1,θdn(i,j)≤θ2.\theta_{cd}^{(i)}\le\theta_1,\qquad \theta_{dn}^{(i,j)}\le\theta_2.

设 zz 表示相机前向向量，朝向约束为（Eq. 10）

zcon⋅znoise(i)∥zcon∥∥znoise(i)∥≥cos⁡φ1,zcon⋅znv(j)∥zcon∥∥znv(j)∥≥cos⁡φ2.\frac{z_{con}\cdot z_{noise}^{(i)}}{\|z_{con}\|\|z_{noise}^{(i)}\|}\ge\cos\varphi_1,\qquad \frac{z_{con}\cdot z_{nv}^{(j)}}{\|z_{con}\|\|z_{nv}^{(j)}\|}\ge\cos\varphi_2.

位置向量与朝向均从 camera-to-world 矩阵读取，四个阈值是超参数。位置夹角在相同半径的环绕轨迹上能反映相机距离，但在一般场景中不能等同欧氏基线；朝向相近也未必有真实视野重叠。这些约束用于控制训练样本难度，而不是充分的几何重叠条件。

4.2 RPPC：将射线力矩改写为参考点坐标

经典 Plücker 表示使用射线方向 dd 与力矩 m=o×dm=o\times d。本文提出 Reference-Point Plücker Coordinate（RPPC），以世界原点到射线支撑直线的垂足替换力矩（Eq. 11）：

r=(p,d),p=o−(o⋅d)d.r=(p,d),\qquad p=o-(o\cdot d)d.

当 ∥d∥=1\|d\|=1 时，p⋅d=0p\cdot d=0。对直线 o+sdo+sd 最小化到世界原点的平方距离，最优 s=−o⋅ds=-o\cdot d，从而得到该垂足。它不一定在相机前方半射线上。

这个变换有一个关键性质：

p=d×m,m=p×d.p=d\times m,\qquad m=p\times d.

因此两种表示在单位方向条件下可逆，RPPC 并没有新增独立的射线信息。区别在于参考点具有直观的位置意义，有限容量的神经网络可能更容易利用它建立相对空间关系。沿同一直线改变 oo 不改变 pp，但改变世界坐标原点通常会改变 pp。这种归纳偏置的有效性需由实验而不是信息量增加来解释。

在网络中，RPPC 不仅作为输入端的像素对齐射线条件与 RGB 拼接。原论文 p.6 还说明，参考点信息通过跳跃连接（skip connection）传递至各 Transformer Block 和 Gaussian Decoder，引导高斯点云生成。这样，参考点的位置表达可以在跨视图特征处理和高斯参数预测时继续发挥作用，而不只是由输入 token 间接携带。这是对作者设计意图的机制解释；论文未给出各处连接的具体张量形状、融合操作或独立的深度预测分支，因此不作进一步实现假定。

4.3 双高斯解码器与对象预热

混合训练中，主干共享，解码器按域选择。物体头的 near/far 为 0.1/4.2，高斯中心裁剪到 [−1,1]3[-1,1]^3；场景头的 near/far 为 0/500。两种深度尺度对应不同参数映射，微调时仅保留目标域解码器。数值来自论文，不能未经尺度标定解释为米制距离。

为鼓励对象点云集中，作者设计预热点分布损失（Eq. 12 原式）：

ℒpd=𝔼k[lt(k)−(lt(k)−𝔼k[lt(k)]Var⁡(lt(k))σ0+𝔼k[|o(k)|])],\mathcal L_{pd}=\mathbb E_k\left[l_t^{(k)}-\left(\frac{l_t^{(k)}-\mathbb E_k[l_t^{(k)}]}{\sqrt{\operatorname{Var}(l_t^{(k)})}}\sigma_0+\mathbb E_k[|o^{(k)}|]\right)\right],

其中 lt(k)=|ut(k)d(k)|l_t^{(k)}=|u_t^{(k)}d^{(k)}|，σ0=0.5\sigma_0=0.5。这里有一处需谨慎理解的数学细节：若内外均值确实针对同一组 kk，且方差非零，则标准化项的均值恰好为零，原式化为 𝔼k[lt(k)]−𝔼k[|o(k)|]\mathbb E_k[l_t^{(k)}]-\mathbb E_k[|o^{(k)}|]。因此不能单凭打印公式确认它实现了目标方差约束；论文未说明是否采用其他实现形式或零方差保护。本文报告的消融结果不提供反推原始代码的充分证据。

整体目标为（Eq. 13）：

ℒ=(ℒde+ℒnv)𝟏iter>iter0+ℒpd𝟏iter≤iter0𝟏object.\mathcal L=(\mathcal L_{de}+\mathcal L_{nv})\mathbf1_{iter>iter_0}+\mathcal L_{pd}\mathbf1_{iter\le iter_0}\mathbf1_{object}.

按原式，在预热阶段对象样本使用点分布损失，之后使用两类图像监督；预热阶段的场景样本字面损失为零，实际采样或处理机制未明确说明。上述疑点是对论文数学表达的独立分析，不代表已经确认代码错误。

5. 实验：共享三维约束是否有效？

训练对象数据包含 Objaverse 730K 和 MVImgNet 220K 样本，场景数据来自 RealEstate10K 和 DL3DV10K。模型先使用32张 A100 混训40K迭代，再使用64张 A100 分别微调对象与场景，训练分辨率由256×256提升到512×512。评估时每实例使用1张输入图及10张测试图。约6秒的推理速度并不代表训练成本低。

6. 技术边界与启发：生成一致性不是真实观测

DiffusionGS 将扩散生成与三维构建统一，避免先生成矛盾图像再事后折中拟合。该机制的价值在于改变先验参与空间推断的方式，而不仅是改用一种更快的渲染器。

然而，Figure 9(b) 中同一输入改变随机种子可以产生不同三维形状及纹理。这种多样性与单图逆问题的欠定性相符。共享3DGS保证同一样本由一个表示渲染，并不保证隐藏区域等于真实结构；Figure 3与8中的深度来自渲染或后拟合，论文未提供真值深度、表面距离或置信度校准的统计评估。

进一步研究可以在已知几何与相机条件的受控数据上，比较逐步三维约束、末步约束及事后拟合，分可见/遮挡区域测量真实深度与表面误差，并检验多种子分歧是否能够预测真实误差。对于水下等参与介质成像，观测还受传播规律影响，颜色、介质和几何可能互相补偿，本文干净 RGB 上的结果不能直接外推。这些是基于本篇机制的后续研究方向，并非论文已验证结论。
