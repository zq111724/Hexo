1.1 标题精读

标题翻译

VGGT: Visual Geometry Grounded Transformer —— VGGT：以视觉几何为基础的 Transformer（亦可译为“视觉几何奠基的 Transformer”）。VGGT 是 Visual Geometry Grounded Transformer 的缩写（p.1、§1 p.2）。这里 grounded 的含义是以三维视觉几何任务及监督建立模型能力，而不是一个具体名为 grounding 的操作。

术语含义

  • Visual geometry（视觉几何）：由图像中的投影关系推断摄像机、深度、空间点与对应关系。视觉几何不等于仅识别物体语义；例如两幅不同视角的同一物体照片，像素位置变化与相机位置、三维点坐标相关。
  • Grounded（以……为基础）：结合 §1 的设计主张，模型在大量带三维标注的数据上学习相关几何量，而不只是进行图像语义预测。它不等于网络中每一步都严格满足多视图投影方程，也不等于显式执行三角测量、BA（光束法平差）或物理仿真。论文强调少量三维归纳偏置；几何任务监督与硬约束是不同概念。
  • Transformer：用注意力在 token 间交换信息。此处对象是多个视角图像的 patch token；§3.2 将帧内注意力与跨帧全局注意力交替，以兼顾每个图像内部结构与多图关联。

【背景知识】同一三维点在不同相机中的投影通常不同。如果网络只独立理解每张照片，则未必能输出统一坐标下的一致三维点。跨帧 token 交互给网络利用共同观测的机会，但不直接证明预测符合极线约束。

可确定与不可确定

标题能确定研究位于视觉几何与 Transformer 交叉领域，不能单独确定输入图像数量、相机是否已知、输出是显式三维点还是隐式场、训练监督方式、是否需要后处理或重建精度。§3.1 才定义联合相机、深度、点图和跟踪特征；§3.3 说明轨迹由独立跟踪模块完成；§4 决定其性能证据。不能从 grounded 推导几何一致性必然成立，也不能仅从 Transformer 一词断言作者发明新的注意力数学。本单元是标题语义分析，具体数学推导不适用。

1.2 摘要精读

背景与问题

【原文事实，p.1 Abstract 与 §1】作者要从同一场景的一张、少量甚至数百张图像中直接推断其主要三维属性。摘要列举相机参数、点图、深度图与点轨迹；正文 Eq. (1) 更细致地区分跟踪特征与由跟踪模块生成的轨迹。过去网络往往为一个任务而训练，例如单目深度或图像匹配；一个场景的完整三维恢复需要整合不同预测，再利用传统优化取得几何一致的结果。

【背景知识】相机内参描述成像投影，外参描述坐标系间的旋转与平移；深度图描述相机观测到的表面深度，点图记录每像素对应的三维位置（在 VGGT 中共享第一相机参考系），跟踪描述同一场景点在各图像中的二维对应位置。它们不独立，但每种表示给训练和使用者提供不同的信息接口。

困难不是传统几何完全无效，而是把几何求解作为每个测试场景的必需迭代步骤带来时间和系统复杂性。§1 对 DUSt3R/MASt3R 的描述指出，其前馈部分处理图像对，多图恢复依赖进一步融合。因此作者希望把跨视角信息整合提前到训练好的网络中，在测试时减少昂贵迭代。

方法与效率

【原文事实】VGGT 采用大规模 Transformer 作为共享骨干，前馈联合估计多个几何量。核心不是对每个场景训练一套网络参数，而是将多幅图的 token 同时输入已训练的模型，通过交替帧内/全局注意力产生跨视角感知特征，再由任务头输出。与逐场景 BA 的差别在于前馈使用固定权重，不需要在每个输入上重新迭代拟合所有几何参数；BA 仍可在其结果上运行。

摘要报告不到一秒的重建效率且优于部分带优化的替代方案。需要区分输入数量与执行模块：Table 9 的 H100 骨干计时 10 帧 0.14 s，20 帧 0.31 s，50 帧 1.04 s，200 帧 8.75 s；另有预测头成本。因而不能把摘要的不到一秒解读为数百图在任意硬件上全部任务恒定亚秒。

1.3 核心贡献

【原文事实】§1 p.2 明确按 (1)–(3) 列出三项贡献；以下按该顺序解释，不把下游实验冒称作者的第四条编号贡献。

贡献一：联合、可变视图数的前馈模型

作者提出 VGGT，在一次前馈过程中支持一张、少量乃至数百张同场景图像，输出相机内外参、点图、深度及跟踪所需信息。针对的问题是既有网络往往单任务，或多图恢复要把图像对的预测通过额外优化合并。

§3.1 Eq. (1) 给出任务定义，§3.2、Figure 2 展示骨干网络。帧内注意力为每个视图的结构建模；全局注意力把所有视图 token 放入联合上下文，使网络可在内部融合跨图证据。特殊第一帧 token 使统一参考系可辨识；每帧不同的预测头从共享特征回归相机与像素级信息。训练同时监督冗余几何量，Table 6 检查这种多任务学习是否有益。§5 Table 9 验证可变视图数的实际计算成本。这里的创新性质主要是方法与系统构建，而非提出新的射影几何定理。

贡献二：无必需后处理的预测可用性

作者声称直接预测有竞争力，往往优于需要慢速后处理的替代方法。这一贡献是实验主张：预测不仅可作为初始化，还能直接作为下游所需结果。Table 3 在 ETH3D 对比依赖全局对齐的 DUSt3R、MASt3R；同时将专门点图头和相机加深度反投影的点图分开对比。Figure 3 的 32 视图案例给出 VGGT <0.6 s、DUSt3R >200 s 的定性示例；Table 9 则量化骨干随输入帧数的资源变化。

【证据边界】单个速度案例不代表整个基准的平均加速；不同分辨率、硬件、输入图数和计算阶段不能直接混算。Table 10 中直接 VGGT 的 AUC@3°/5°/10° 为 39.23/52.74/71.26，低于 VGGSfMv2 的 59.32/67.78/76.82；因此“往往”并不是“总是”。

贡献三：保留 BA 作为可选几何精化

作者发现联合前馈预测能为 BA 提供高质量的相机和三维点初始化。在投影约束下进一步调节相机与点，可以弥补纯预测未严格满足的重投影一致性。附录 C 说明直接预测三维点减少传统初始化所需的三角化与迭代精化成本。Table 10 中 VGGT+BA 的 AUC@3°/5°/10° 达 66.37/75.16/84.91，计时 1.8 s，相比直接输出 0.2 s 增加了后处理，却在该实验中高于 VGGSfMv2 的准确度。

【背景知识】BA 通常最小化观测像素与三维点重新投影间的残差；良好初始化有助于局部优化进入更好的收敛区域。但原文并未证明任意场景都能收敛到全局最优。这也不等于 BA 是 VGGT 前馈模型的一部分。

贡献的性质

贡献一是任务统一与架构设计；贡献二是准确率/效率的实验验证；贡献三是将学习预测与经典优化互补的实验和系统贡献。另有摘要及 §4.6 的表示迁移验证，证明特征有复用潜力，但动态跟踪与 NVS 均有具体微调协议。DINO、DPT、CoTracker2、注意力机制和 BA 均是作者承接的技术，不能把这些组件的发明归给本论文。需进一步核验消融才能判断交替注意力与联合监督各自贡献；尚无理论保证普适三维一致性。

1.4 结论与讨论

结论主张

【原文事实】§6 p.11 总结 VGGT 能从可达数百个输入视图中直接估计关键三维场景属性，在相机、深度、稠密点云与点跟踪方面取得领先结果。强调神经网络优先路线与依赖任务专用优化后处理的传统流程不同，并将简洁性和效率视为实时应用的优势。§1 第三条贡献补充指出 BA 并未被禁止，而是从必需步骤变为可选精化。

明确局限

§5 p.10 的作者自述边界如下：

  1. 不支持鱼眼或全景图像。§3.1 的 9 维相机参数含四元数、平移和二维视场角，假定主点居中；这与需要不同投影模型的鱼眼和全景图有明显设定差异。此因果解释属于合理推断，不是作者已给出的形式证明。
  2. 输入出现极端旋转时重建性能下降。网络从训练数据学习旋转相关图像与几何关系，不是对任意旋转严格不变的几何求解器。论文没有提供所有旋转角度的误差曲线。
  3. 能处理轻微非刚体运动，但显著非刚性变形时失败。静态共享几何在物体变形时不再能由一个不随视图变化的三维位置解释全部投影；动态视频迁移实验通过替换/微调跟踪器，并不消除基础重建的这一局限。
  4. 计算开销随输入帧数增长。Table 9 在单 H100、336×518 下报告 1 帧骨干 0.04 s/1.88 GB，200 帧 8.75 s/40.63 GB；相机和 DPT 预测头另有开销。全局自注意力朴素实现的 token 对交互成本高；逐帧执行 DPT 可减少部分显存，却不能消除共享骨干跨帧交互成本。

§5 还报告单图推理无需复制图像，尽管训练并非专为单视角设计；Figure 7 只提供定性例子。作者发现 GT 坐标尺度归一化有用，预测值再次归一化并非收敛必要条件，且可能导致训练不稳定。这些是具体训练经验而非一般数学定理。

未来方向

作者提出可用针对性数据微调改善鱼眼、极端旋转或非刚性适配，但本文未完成这些验证。另指出可微 BA 在小规模实验中有希望，使用 Theseus 使训练每步约慢四倍，因此未纳入正式训练；无显式三维标注场景下可将其作为监督，是作者建议的未来路线，不是本论文已经完成的无监督训练成果。可采用面向大模型的推理优化缓解全局注意力开销，仍需实际实现和评估。

证据边界

【独立评价】“适合实时应用”是效率上的潜在适用性，不能读成任何图像数、任何设备或所有任务头都满足固定帧率。直接 VGGT 也不在所有相机阈值上领先（Table 10）；加 BA 的结果与纯前馈应分开。论文结果是其测试设置下的实证结论，不意味着单张图片可唯一恢复不可见表面的真实几何，也没有证明在训练分布之外的所有场景可靠。没有进行外部代码/复现实验核验。数学详细推导留待方法及公式单元，本结论单元不增加原文未给出的证明。

§5 Single-view Reconstruction 明确称训练未专门针对单图，但网络结构允许 N=1N=1；附录 B 训练每场景采样 2–24 帧。此时全局注意力 token 域等于单帧域，帧内与全局层仍然存在但都只看一个图像；第一相机为参考，外参按 §3.3 设定为单位变换。深度与点图必须由输入的图像结构以及训练得到的先验推断，无法通过真实多视角视差三角化。Figure 3 也有单张油画比较。

【背景知识】即使针孔内参已知，单个像素仅约束三维点落在一条视线上，并未给出唯一距离。纹理、遮挡、物体常见形状和透视线索能为预测提供统计信息，不能从观测唯一恢复深度；整体比例也可存在尺度自由度。对画作或线稿尤其应区分物理成像平面与画面描绘的虚拟场景。

证据边界

这些结果展示原生单图结构支持和定性泛化现象，但不是单目深度基准上的误差表，也不能证实未见场景的每个点在真实三维位置上准确。不可见区域、绝对尺度、画作所绘形体的真实几何均缺乏独立真值。作者的泛化主张在这些例子上有直观支持，尚未构成单图可靠性的一般证明。

核心科学问题

任务是多视角几何估计。更具体的问题是：在任意数量、通常无序且相机未知的图像中，能否将原本需要多阶段逐场景优化的互相依赖几何量，通过一个训练后固定的网络直接预测，同时在准确性、速度与泛化之间取得有竞争力的结果？它不仅是缩短运行时间，还要让不同图像中同一场景的几何处于共享坐标，学习跨帧的关系。区别于逐图单目深度，多个视角的相机、点和深度共同受同一个场景约束；区别于传统已知相机 MVS，位姿也需估计。论文不以某个新的可辨识性定理为目标，而是统一任务表示、网络设计及实验验证。Fig.2 和 Table 5/6 是机制证据，Table 1–4 是任务证据。

不可辨识性

【背景知识】对于静态透视成像 u∼K(RX+t)u\sim K(RX+t)，若世界点与相机平移共同乘正数 ss，归一化投影不变。没有外部尺度先验时绝对米制尺度不可由普通多图成像唯一确定。选择第一相机参考系并以 GT 点到原点的平均距离规范化消除训练标签的任意全局坐标和尺度选择（§3.4），并不补充物理观测。单视角还存在每像素沿视线移动的深度自由度，非重叠视角可能没有共享匹配；不同场景布局可产生类似输入。学习先验能选择合理解，不能保证真实解唯一。基础模型面对显著非刚性、极端旋转和非针孔视角仍受限（§5），动态跟踪适配另论。因此 VGGT 的任务既不是只处理 sparse-view，也没有证明稀疏观测本身的所有退化已解决。

4.2 研究背景与动机

优化链条

【原文事实，§1、§2、§4.1–4.3】传统 SfM 通常先检测与匹配特征、估计相机、三角化、BA 精化，输出稀疏几何；再借助已知相机运行 MVS 得到稠密深度。传统系统可让多视图约束显式耦合，但每个新场景都要重复求解，且中间匹配或位姿错误会传递到后续 MVS。VGGSfM 将多个环节可微化，仍利用测试时 BA。DUSt3R/MASt3R 直接对图像对预测对齐点图，绕过已知相机输入，但多视图时仍需将多个图像对的结果全局对齐。若完整枚举无序对，候选数为 N(N−1)/2N(N-1)/2；实际算法可以使用稀疏图而非全部枚举，不能把此式当作论文给定的实际调用次数。关键瓶颈在于重复调用和跨对的尺度/坐标/对应一致性优化。作者希望把这些跨视角关系的学习放到训练中，把每场景求解更多地摊销为一次推理。

联合估计

【背景知识】已知深度和相机可反投影点图，已知一致点图与像素对应也可建立 PnP 相机求解，几何量存在冗余。若网络只学习单一复杂输出，训练信号不一定显式强调各潜在因素；联合监督可让共享特征分别承受位姿、局部深度、全局点坐标及对应的误差梯度。这样，即便直接点头在推理时不是最优路径，其损失仍可能约束骨干。作者在 §3.1 明确提出 over-complete predictions，并未声称各头通过硬性投影等式互相约束。

【合理推断】两幅图看见同一墙面，点图头既要判断像素的相机深度，又要判断它在全局的旋转平移位置；相机头可专门学习全局坐标关系，深度头可专注每幅视图几何，从而减少一个稠密头同时学习两种映射的负担。Table 3 显示这种分解在 ETH3D 有收益，而不是数学上无条件必然优于直接点头。

实验证据

Table 3 的 0.2 s 对 7/9 s 及 Figure 3 的 32 帧示例提供多对全局对齐成本的实证。Table 5 的 2L 同参数消融、Table 6 的逐项损失消融说明 AA 与联合监督的价值；Table 9 明确单 H100 的资源扩展边界。因此困难是既有经典问题与新工程目标的结合，非作者首次发现。训练代价仍高（64 A100 九天），全局注意力也随帧数增长；这属于将部分测试成本迁移到离线学习，并非所有计算和优化从系统中消失。若每个训练后的模型用于大量新场景，摊销优势有意义，论文未给端到端生命周期成本比较。无重叠和单图的结果虽显示泛化潜力，尚未控制观测基线、先验和数据规模以证明其真实几何能力的来源。

4.3 相关工作与定位

SfM 与 MVS

【原文事实，§2、附录 E】SfM 主要解决相机估计与稀疏结构。经典 incremental SfM（COLMAP）逐步加入图像、三角化及 BA，global SfM 则从相对关系同时求全局位姿。学习型 keypoint、SuperGlue/LightGlue 等提高匹配质量，PixSfM 使用更细致的特征/几何优化；VGGSfM 将流程变为可微框架并在 phototourism 取得强性能。另有将相机作为回归问题的路线（PoseDiff、RelPose、RayDiff 等；附录 E），以及 Ace-Zero 回归场景坐标、FlowMap 通过深度中间量估计相机。本篇 VGGT 选择直接联合回归而非把显式 BA 放进训练计算图，推理可选择 BA 后处理。

5.2 共享骨干：DINOv2 与 Alternating-Attention

图像 token

【原文事实，§3.2、§3.3、附录 B、Figure 2】每幅 RGB 图经 DINOv2 patchify 为 tiI∈ℝK×Ct_i^I\in\mathbb R^{K\times C}，14×14 patch，位置嵌入描述图像局部空间位置。对于长边 518、短边 336 的输入，按完整规则网格的背景计算为 37×24=888 个图像 patch token（不计特殊 token），不是另从代码核实的实际张量。DINO 的预训练图像特征先在每幅图内建立纹理、物体结构等表示；作者比较 14×14 卷积 patchify 并报告 DINOv2 稳定性与性能更好，未给具体消融表数值。

每帧再拼接一个 camera token tigt_i^g 及四个 register token tiRt_i^R。这些是学习得到的初始向量，不是外部输入的真实相机值。首帧特殊 token 与其他帧共享的特殊 token 使用不同参数，形成参考帧标识；各帧经帧内注意力接触对应图像后，更新后的 token 变成帧特异的。拼接序列概念上为 N×M×CbN\times M\times C_b，M=K+5M=K+5，以骨干维数为准。register token 只参与信息处理，最终丢弃。正文的 C/C′ 等记号不完全一致，不把每个中间通道数强行等同，附录明确 attention 隐维 1024。

交替注意力

每个 block 各含一层 frame-wise self-attention 和一层 global self-attention，共 L=24 blocks/48 层注意力。帧内阶段对每个 i 的 M 个 token 独立自注意力，保持每幅图的相对局部结构；全局阶段将 N 帧 token 同置于一个 self-attention 域，任何查询可从其他图及自身取得信息。这里不是将一个固定 reference 作 query、另一图作 K/V 的传统 pairwise cross-attention；也没有每个视图间先显式求 F/E 矩阵。图中蓝黄块只是交替关系，不把图示画法当作所有实现的精确顺序约定。

假设一帧中墙面纹理难以确定位置，global 层可结合另帧门窗等线索更新墙面 token；后一帧内层能把这一跨帧信息传给当前图的其他 patch 和 camera token；重复后逐帧及跨帧信息交互。其训练监督来自真实几何而非 attention 权重的显式对应标签。附录 B：1024 hidden、16 heads（常规等分为每头 64 维），使用 PyTorch MultiheadAttention 与 flash attention；Table 5 比较同 2L、参数量、头数和隐藏维度的变体，AA 直接点 Overall 0.709，global-only 0.827、cross 1.061。

1. 摊销的几何推断不是消除几何

依据冻结报告 §4.2、§5.4、§7.1 与论文 §1、Table 1/10。传统逆问题通常写成每个场景求解 ẑ=arg⁡min⁡zE(z;I)\hat z=\arg\min_z E(z;I)；zz 可包含相机、点等变量。VGGT 的训练将许多场景的经验风险最小化到共享参数 θ\theta，测试时执行 ẑ=fθ(I)\hat z=f_\theta(I)，用离线学习替代一部分逐场景求解。这是背景形式化，不是论文的额外损失。它说明为何固定网络能在十帧约 0.2 s 得到相机，却仍可在 IMC 加 BA 将 AUC@3 从 39.23 提高至 66.37。反事实：若网络已经严格找到每个场景的同一 BA 目标的最优解，并且 BA 未改变目标与可用信息，进一步优化不应明显提高该目标；实际 AUC 增益表明纯前馈仍有可精化空间，但 AUC 不是 BA 目标，不能据此证明网络残差的具体来源。前馈与优化是求解策略不同而非互斥的研究范式。

ehead(y)=∥P̂i(y)−U(ĝi,D̂i)(y)∥2.e_{head}(y)=\|\hat P_i(y)-U(\hat g_i,\hat D_i)(y)\|_2.

它与 GT 几何误差互补：两者都错但彼此相容时 ehead=0e_{head}=0；二者相差大时说明至少一条输出路径不相容，但不能仅凭它判断哪个头正确。例：正确深度为 5，模型的两个输出路径分别对应深度 4.5 与 4.5，头间误差为零仍偏离真值。因而可在已知尺度规范/对齐的验证集同时评估 eheade_{head}、GT 点误差与重投影误差，不应把内部一致性直接替代外部真实性。

RP-A：稀疏观测中，学习先验能否可靠地补偿几何约束缺失？（优先）

现象和未知： Fig.3 展示无重叠两图，Fig.7 展示单图；但没有真实几何误差和重叠率曲线。未知是何种观测退化导致模型预测从证据主导转为先验主导，以及错误是否可被识别。

可证伪假设： 在控制场景、相机模型和有效像素的情况下，降低重叠率/基线信息会使点图与相机误差增加；若训练先验与测试场景一致，部分误差可缓解；如果先验与场景冲突，即使视觉合理也会出现系统性几何错误。

验证机制： 选具有相机、深度及点云 GT 的静态数据，按 N=1/2/4/8/10 等分组；在固定 N 下改变共视比例、相机相对角、基线，并避免把宽基线与低重叠混为单变量。设计外观相似但结构不同的合成场景及重复纹理对照，保持相同输入分辨率和网络权重。真值对齐后评价 Acc./Comp./Overall、尺度规范内相机 RRA/RTA、可见区域深度误差、置信 risk–coverage。已有直接点与派生点两种输出作为内部基线；如需比较其他模型，应另做文献和代码核查。逐场景统计而非只给均值，确保相机退化（近零平移）不污染角度指标。

成功/失败判据： 在多场景和独立种子上出现随退化程度稳定变化的误差/置信曲线，且对先验冲突的控制能区分外观与几何来源，支持假设；若控制后趋势消失或误差主要由分辨率/训练域引起，则不能把差异归因稀疏观测。若单目或无共视的真值不可辨识，报告多解而非要求物理上不可能的唯一重建。可行性较高：先不训练新网络。需核实可获取的模型、数据划分与训练重叠。

可证伪假设： 结合跨头残差、预测置信、共视/重投影一致性比单独置信更能预测 BA 的实际收益；按信号选择少量场景优化可在接近固定全量 BA 的质量下减少平均开销。不是声称所有低一致性样本都会受益。

验证机制： 同一冻结模型生成 PP, U(g,D)U(g,D) 与 tracks，统一 gauge 后构建 eheade_{head}、有效共视数、重投影残差和置信统计。定义 GT 误差改善 ΔE=E_before−E_after（越大越好，此处 E 为指定几何误差而非色差）；使用同一 BA 实现、同一阈值与初始化，记录失败/无效解。训练/验证分割阈值或简单分类器，测试单纯前馈、总运行 BA、固定随机比例运行 BA、按置信、按相容性及组合策略；对视角数、重叠、纹理、模型误差分层。报告 AUC 或几何误差、场景时间和最坏失败率，不只画平均速度。

成功/失败判据： 在未见场景验证集，组合信号能提高 BA 收益排序的 Spearman 相关性/识别有效优化的精度，并在预先设定相同时间预算下降低几何误差或相同误差下降低时间。如果低相容性多数源于错误跟踪使 BA 更差，或置信没有域外校准，则假设不成立，需重新设计选择/拒绝机制。可行性中等：必须实测 BA 与 GT；论文只给均值，未给联合残差，需新实验。不能把相容性提高当作真值误差必然降低。

RP-C：非理想成像下，几何错配与外观变化能否被区分？（探索）

现象和未知： §3.4 各帧独立颜色增强、Fig.3 重复/均质纹理例暗示外观鲁棒性重要，但本文没有散射介质建模和水下评测。跨视角特征不一致可能由几何错配或光传播变化共同引起。

可证伪假设： 在固定几何/相机与可见性下，仅改变距离相关的成像传输会改变 VGGT 的跟踪/深度置信与误差；若某种机制能利用与介质影响区分的几何证据，其匹配排序与误差校准将更稳定。没有声称介质建模一定优于一般域适配。

验证机制： 先采用具有清晰图、相机、深度真值的合成静态场景，在同一几何和观察子集上控制成像变化程度（无介质/不同散射衰减水平），独立控制 N、重叠和纹理。可建立已知传输的理想恢复对照、只进行颜色增强/通用域适配的对照和固定原模型。评价可见点几何、跟踪像素误差、pose AUC、置信校准；若有合成任务，渲染指标独立报告。应明确介质模型与成像假设、深度真值定义、测试集与训练分离；不从原论文补造真实水下性能。

成功/失败判据： 固定几何的成像变化产生可重复的特征/几何误差变化，候选机制在相同观察条件下减少该误差且没有在清晰图明显损失；若差异只由低对比或噪声、模型规模造成，或图像恢复好而几何无改善，不能支持机理假设。可行性比 A/B 低，需要可控成像模拟或校准数据、领域文献核查。先做诊断再决定是否提出新方法，不预设必须使用特定渲染或介质表示。

核心知识不是 Transformer 可以做几何这一口号，而是把原来分阶段的相机、深度、点坐标和对应关系的估计摊销到同一组共享权重。数据流：RGB 图 → DINO patch token 与 camera/register token → AA 共享骨干 → 相机头和各帧 DPT → 相机/深度/点图/跟踪特征 → 可选二维查询跟踪、相机深度反投影或 BA。监督流：首相机与 GT 尺度统一 → 四类损失从各头返回共享骨干；并不意味着推理每个头严格由另一头计算。研究逻辑：减少对多图 pairwise fusion 与测试迭代的依赖 → 共同学习互有关联的几何量 → 以同参数注意力消融、多任务损失消融及不同任务比较验证 → 保留 BA 与下游微调作为额外选项。三条逻辑不可混用。

不看论文时应能回答的关键问答

为什么第一帧特殊？ 因为世界坐标有 gauge，网络需确定共同参考。改变非首帧顺序应对应重排输出，换首帧则改变参考；尺度另由 GT 点平均距离规范。此设计不代表绝对物理尺寸确定。

相机和深度都能生成点图，为什么仍训练独立点头？ 标签几何冗余但学习信号不相同，Table 6 支持联合学习，Table 3 在推理端派生点更准确。若两个头都存在系统偏差，几何相容也可能错误。具体哪个输出更可靠需要 GT 或可验证几何证据。

全局注意力是不是极线匹配？ 不是。它提供所有 token 的交互域，自注意力学习权重；相机约束由训练目标间接提供。Table 5 支持结构优越，但没有 attention 与真实对应的可解释性实验。

为什么对单图/非重叠图不应把结果当物理真值？ 观测投影中缺少充分几何约束，先验可选择合理结构，无法证明唯一解。需有独立几何真值、受控重叠率或不确定性评估。画作的描绘空间与实际画布物理表面甚至是不同任务。

有没有消除优化？ 基础模型不需每场景迭代，Table 1/3 指定十帧快速；IMC 纯前馈不全面领先，加入 BA 明显提升。学习式预测与几何优化可以互补。

可以直接处理动态视频和 NVS 吗？ 基础静态跟踪输出二维对应；动态跟踪需要 CoTracker2 改造并微调。NVS 需目标射线 token 与 RGB 输出头适配，源相机无需已知不代表无目标相机条件；Table 7 不评估真值几何。

几百帧不到一秒吗？ Table 9 只是单 H100 特征骨干，50 帧 1.04 s、200 帧 8.75 s，还需选择头及后处理。不能使用题注替代实测数据。

研究启发与未解决问题

对稀疏/未知相机几何，先分清“可输出”与“可辨识”、相对规范与物理尺度、内部一致性与真值误差。一个好的模型可能因统计先验而快速预测，研究问题应以观察变化造成何种误差、先验何时可靠、怎样验证为起点。当前开放问题：不同 N/共视/基线的质量曲线、相容性与真实误差关系、置信校准、BA 的自适应取舍、训练数据和模型规模的独立影响、参与介质或非针孔/动态域适配。它们均需实证；目前依据仅为本文及标注的背景推导，没有宣称跨论文已建立关系。

GLOSSARY：术语与相近概念

术语源于论文 §2–5、附录 A–E 与冻结报告 §4–7；补充数学定义采用通用背景，不把实现细节当作论文事实。

英文 中文 含义及辨析
SfM (Structure from Motion) 运动恢复结构 多图估计相机与稀疏三维点；不同于已知相机的稠密 MVS。
MVS (Multi-view Stereo) 多视图立体 通过共视几何估计稠密表面，传统设定相机已知。
BA (Bundle Adjustment) 光束法平差 联合优化相机和三维点使重投影残差降低；不是训练骨干的 attention。
PnP (Perspective-n-Point) 透视 n 点 从 2D–3D 对应和适当相机内参估计姿态；区别于仅 2D–2D 的相对姿态求解。
Pose / Intrinsics / Extrinsics 相机位姿/内参/外参 内参为投影参数，外参为坐标刚体变换；VGGT 回归四元数、平移、视场角。
FoV (Field of View) 视场角 投影视角宽度，针孔下与焦距/图像尺寸对应；不等于相机旋转。
Depth Map 深度图 每个像素观测表面距离/深度；须区分 z-depth 与射线长度。
Point Map 点图 每像素三维坐标，VGGT 正文以首相机参考系表述；并非无序点集或体积密度。
Viewpoint-invariant 视点不变的 同一三维场景点在统一参考系表示；不等于每个预测严格相等。
Gauge Freedom 规范自由度 在相机/点共同变换时投影不变的整体坐标尺度自由度；规范化不是获取真实尺度。
Unprojection 反投影 将像素和深度映射为三维点，必要时用外参逆变换；需明确深度和坐标 convention。
DINOv2 自监督视觉特征骨干 用于 patch token 化；不等于 VGGT 完整几何模型。
AA (Alternating-Attention) 交替注意力 每个块内在帧内与全局自注意力域交替，非传统 cross-attention。
Camera/Register Token 相机/寄存器 token 可学习向量，前者用于相机头，后者处理后丢弃；首帧使用特异参数。
Permutation Equivariance 置换等变 重排非首帧输出随之重排；不是不变性，也不涵盖改变参考帧。
QKNorm / LayerScale QK 归一化/残差缩放 稳定训练技巧；本文未给完整实现公式。
DPT (Dense Prediction Transformer) 稠密预测 Transformer 多层 token 上采样恢复像素级特征；骨干负责主要跨帧融合。
Over-complete Predictions 冗余联合预测 同时监督可互推的几何量；不同于强制它们满足一致性等式。
Aleatoric Uncertainty 偶然不确定性 与数据噪声/歧义相关；本文乘权形式实际呈置信度意义，未校准方差。
Tracking-any-point / Visibility 任意点跟踪/可见性 查询像素在其他帧的对应及是否可见，基础任务不要求时间顺序。
RRA / RTA 相对旋转/平移准确度 根据相对角误差阈值得准确率；RTA 不等同米制平移精度。
AUC@θ 阈值曲线下面积 相对位姿角阈值范围内表现；不同阈值/协议不可直接比较。
Accuracy / Completeness 准确性/完整性 预测→GT 与 GT→预测最近点距离，均越低越好。
Overall / Chamfer distance 综合距离/Chamfer 距离 本文取 Accuracy 与 Completeness 平均；其他文献定义可能不同。
Umeyama Alignment Umeyama 对齐 估计点集间变换以比较形状，削弱整体坐标规范影响；非绝对尺度指标。
ALIKED / RANSAC 关键点检测/鲁棒随机采样 ScanNet 双图评估使用的检测与姿态求解环节，非 VGGT 主骨干。
NVS (Novel View Synthesis) 新视角合成 已给目标视角时合成 RGB；本篇经过下游适配。
Plücker Rays Plücker 射线表示 用方向和矩描述空间直线，目标相机条件；非源相机已知的要求。
PSNR / SSIM / LPIPS 信噪比/结构相似性/感知距离 图像评价，前两者越高越好，LPIPS 越低越好；非几何真值误差。
CoTracker2 点跟踪模型 基础 VGGT 跟踪模块借鉴其结构；动态迁移替换特征骨干并微调。
AJ / δvis_avg / OA 平均 Jaccard/可见点定位准确度/遮挡准确度 TAP-Vid 三种评价量，分别联合跟踪遮挡、可见点位置及遮挡二分类。
Flash Attention 高效注意力实现 降低内存访问及中间矩阵物化，仍有全局 token 对的算术开销。
Amortized Inference 摊销推断 通过离线训练学习跨场景推断映射，测试减少迭代；背景概念，不是论文命名新方法。
