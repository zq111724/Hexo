Depth Anything 3：从任意视图恢复视觉空间

阅读完整精读报告

论文版本： arXiv:2511.10647v1（2025-11-13）；核验时为最新版（2026-11-27）。

官方资源： arXiv | PDF | Project Page | Code

1. 研究问题与核心技术逻辑

三维视觉中，深度估计、相机位姿估计、点云重建和新视角合成常被设计成不同任务。它们并非相互独立：给定相机与深度，就能够反投影出三维点；多视角点云是否对齐，又取决于深度与相机估计是否彼此一致。Depth Anything 3（DA3）关注的是如何用一个可接受不同数量图像的几何基础模型（geometry foundation model），统一这些推断任务的基础表示。

设输入为 NN 张图像，可选已知相机参数。主模型输出每张图像的深度图与射线图，以及一个轻量相机头给出的相机参数。由此可以获得可见表面点图并融合场景几何，也能进一步为前馈式 3D Gaussian Splatting（3DGS）提供几何基础。单图时主要依赖学习到的深度先验；多图时还可以利用跨视角的几何对应。这里的“任意视图”指模型能够接收不同数量的图像及可选位姿，不意味着任意图像组合都能恢复完整或唯一的真实场景。

作者的核心设计是解决三个彼此关联的困难：

困难 设计选择 技术作用
多种几何预测目标相互依赖，独立回归可能不一致 Depth-Ray 表示 以深度选择表面、射线表达相机几何，直接组合三维点
多视图模型复杂的专用结构不利于充分复用单图预训练 单个标准 DINOv2 Transformer，按需跨图注意力 保留已有视觉特征能力，通过 token 重排引入其他视角信息
真实深度监督稀疏、噪声与缺失会损害细节 合成数据训练的相对深度教师、与真实标签对齐 用真实有效深度锚定尺度，同时提供密集的局部结构监督

这三项机制形成完整链条：Depth-Ray 确定需要预测的几何量，Transformer 负责从不同观测推断这些量，Dual-DPT 将共同视觉特征解码为两个空间对齐的输出，教师与联合损失提供训练约束。额外的 Gaussian head 再将预测几何用于渲染。它们分别回答表示、推断、监督和应用的问题，而不是四个彼此独立的功能。

2. Depth-Ray：从像素深度到统一三维空间

2.1 为什么深度和射线已经足以描述几何？

设像素齐次坐标为 𝒑=(u,v,1)T\mathbf p=(u,v,1)^T，相机内参为 𝑲\mathbf K，𝑹\mathbf R 为相机到世界坐标的旋转，𝒕\mathbf t 是世界坐标下的相机中心。按照论文 §3.1 的反投影关系：

𝑿c=D(u,v)𝑲−1𝒑,\mathbf X_c=D(u,v)\mathbf K^{-1}\mathbf p,

𝒅=𝑹𝑲−1𝒑,𝑷=𝒕+D(u,v)𝒅.\mathbf d=\mathbf R\mathbf K^{-1}\mathbf p,\qquad \mathbf P=\mathbf t+D(u,v)\mathbf d.

深度 DD 决定沿射线的表面位置，𝒅\mathbf d 决定射线方向，𝒕\mathbf t 决定射线起点。射线图（ray map）每像素六维 𝑴=(𝒕,𝒅)\mathbf M=(\mathbf t,\mathbf d)，深度图每像素一维。按论文 §3.1 的数学定义，对 NN 张图像，全分辨率深度图与射线图分别为 N×H×WN\times H\times W 与 N×H×W×6N\times H\times W\times6；在同一像素坐标上组合即可得到 N×H×W×3N\times H\times W\times3 的世界坐标点图。这是表示层的尺寸约定，并非网络原始输出的尺寸：Figure 2（PDF p.5）将 Ray 标为 N×H2×W2×6N\times\frac H2\times\frac W2\times6，具体区别见 §3.2。

注意论文的方向向量并非单位向量。对于标准针孔模型，𝑲−1𝒑\mathbf K^{-1}\mathbf p 的第三分量为 1，DD 是相机轴向深度，而不是欧氏射线长度。若将方向单位化为 𝒅‾=𝒅/∥𝒅∥\bar{\mathbf d}=\mathbf d/\|\mathbf d\|，必须同时将深度改为距离 ℓ=D∥𝒅∥\ell=D\|\mathbf d\|，才能保持 𝑷=𝒕+ℓ𝒅‾\mathbf P=\mathbf t+\ell\bar{\mathbf d}。例如 𝒅=(0.6,0.8,1)\mathbf d=(0.6,0.8,1)、D=2D=2 时，位移为 (1.2,1.6,2)(1.2,1.6,2)，距离为 222\sqrt2。这是理解射线表示与深度定义必须配套的关键。

相对直接回归独立的点图，作者希望将局部表面深度与相机几何因子分离，让三维点由明确的几何关系导出。Point Map 直接描述可见表面坐标，却不显式分离表面深度和成像射线，也不自动保证跨图对应一致；Depth + Camera 在正确相机参数下同样可以反投影，但要求网络准确回归全图共享的相机参数。例如直接回归旋转矩阵需满足 𝑹T𝑹=𝑰\mathbf R^T\mathbf R=\mathbf I、det⁡𝑹=1\det\mathbf R=1（合法旋转的约束）；四元数等参数化也能表达旋转，并非不可学习。Depth + Ray 改为在稠密像素网格上学习起点与方向，不必直接回归正交矩阵，并使深度和相机几何在空间位置上对应。代价是独立预测的射线未必组成合法的中心投影相机。Table 6 比较的是这些学习目标组合（含 depth+pcd+cam），而非数学表示能力的唯一性证明。理想情况下，真实同一表面点在不同图像中反投影至同一世界位置，即可融合。补充一阶误差分析：

δ𝑷≈δ𝒕+𝒅δD+Dδ𝒅.\delta\mathbf P\approx\delta\mathbf t+\mathbf d\,\delta D+D\,\delta\mathbf d.

这说明远处结构特别容易受到射线方向误差影响。单图深度边缘清晰并不足以保证三维几何一致，仍要考虑相机和方向估计。

2.2 从稠密射线图恢复相机

理想中心投影中，一幅图像的所有射线具有同一原点，方向由相机内外参确定。论文 Eq. (1) 将预测的射线起点求平均：

𝒕c=1HW∑h,w𝑴(h,w,:3).\mathbf t_c=\frac{1}{HW}\sum_{h,w}\mathbf M(h,w,:3).

方向部分则通过射线之间的投影关系求解。论文 Eq. (2) 对矩阵 𝑯\mathbf H 写出如下方向拟合目标：

𝑯*=arg⁡min∥𝑯∥=1∑h,w∥𝑯𝒑h,w×𝑴(h,w,3:)∥.\mathbf H^*=\arg\min_{\|\mathbf H\|=1}\sum_{h,w}\|\mathbf H\mathbf p_{h,w}\times\mathbf M(h,w,3:)\|.

叉积为零表示两个方向平行，因此可以把每个像素变成线性约束。若预测方向为 𝒎i\mathbf m_i，则无噪声时 [𝒎i]×𝑯𝒑i=0[\mathbf m_i]_\times\mathbf H\mathbf p_i=0。堆叠所有对应得到 𝑨vec⁡(𝑯)=0\mathbf A\operatorname{vec}(\mathbf H)=0，标准 DLT（直接线性变换）以最小奇异值对应的右奇异向量求解平方最小二乘；之后借助矩阵分解提取相机参数。

这里有两处需要区别原文与标准推导：第一，原文 Eq. (2) 写的是各叉积范数之和，通常的 DLT 则最小化平方和，在存在噪声时二者并非严格等价。第二，若沿用上节 camera-to-world 的 𝑹\mathbf R 定义，像素到世界射线的映射应与 𝑹𝑲−1\mathbf R\mathbf K^{-1} 成比例，而其逆映射与 𝑲𝑹T\mathbf K\mathbf R^T 成比例，后者可自然用 RQ 分解提取内参与旋转。原文写 𝑯=𝑲𝑹\mathbf H=\mathbf K\mathbf R，未充分说明与前文的变换方向如何对应。这里保留原文记号疑点，不将某种实现推断写成作者已验证的算法。

由于逐像素求解有额外计算开销，实际网络另设相机头，从每图的相机 token 预测九维参数（3 维平移、4 维旋转四元数、2 维视场角）。这也是为什么论文称 Depth-Ray 足以表达主要几何信息，却仍保留相机预测头。稠密预测不一定严格满足刚性针孔相机，因此两种相机恢复路径也不必在噪声下完全相同。

2.3 表示充分性与观测可辨识性

Depth-Ray 在给定正确预测时足以表达可见几何，但不能消除单目或稀疏观测的固有歧义。例如，在统一世界尺度变换下，同时将 DD 和 𝒕\mathbf t 乘以同一正数，得到的三维点按比例缩放，却可保持透视投影不变。主模型的尺度规范与度量深度模型需要分别理解。遮挡面、无共视区域以及退化相机轨迹也不能仅通过改变输出表示得到真实答案。

3. 单个 Transformer 如何实现多视图推断？

沿 Figure 2 的实线阅读前向信息流：RGB 图像经 patch embedding 得到图像 token；已知相机时将相机参数编码成 camera token，未知时用可学习 token。两类 token 一起进入单个 Transformer；输出的图像 token 送入 Dual-DPT 产生深度和射线，再按对应空间位置组合成点图。输出的 camera token 则进入轻量相机头 DcD_c，直接产生相机参数，而非将点图再送入该头。图中的 Teacher Model 和各损失连接属于训练监督：教师生成的深度标签经对齐后参与监督（§4.3），主 DA3 在推理时不需要额外运行教师。下文分别展开注意力与解码机制。

3.1 输入自适应跨视图注意力

DA3 使用标准预训练 DINOv2 ViT。每张图像先转为 patch token，随后加入一个 camera token。相机已知时，轻量 MLP 将视场角、旋转四元数和相机平移编码为 token；未知时使用共享的可学习 token。它们与图像 token 一起参与所有注意力层。因此相机条件并非直接替换预测结果，而是作为推断所使用的信息。

设批量大小为 BB，视图数为 NN，每图 token 数量（含相机 token）为 TT，特征维为 CC。输入逻辑形状为 [B,N,T,C][B,N,T,C]。图内注意力将其整理为 [BN,T,C][BN,T,C]，每个 query 只能访问同图 token；跨图注意力将其整理为 [B,NT,C][B,NT,C]，每个 query 可以读取同组其他视图 token。随后将输出还原为原来的图像与 token 布局。

以标准单头注意力作为说明：

Q=XWQ,K=XWK,V=XWV,Q=XW_Q,\quad K=XW_K,\quad V=XW_V,

Y=softmax⁡(QKTdk)V.Y=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V.

投影权重的形状由特征维决定，而不依赖序列长度，因此不需要另建一套专用 Transformer 权重。改变的是交互范围：跨图注意力可以传递对应结构、遮挡与相机运动线索，但并不是显式的极线匹配算法，仍依赖训练获得正确的跨图推断能力。

全图交互比图内交互更昂贵。仅计密集 attention score，前者约为 O(BN2T2)O(BN^2T^2)，后者约为 O(BNT2)O(BNT^2)。论文选择前段逐图处理，后段交替图内/跨图注意力，前后块数量比例 Ls:Lg=2:1L_s:L_g=2:1。这样既能保留预训练视觉特征的工作方式，又能在后段交换几何信息。当 N=1N=1 时，两种布局的注意力域相同，主干自然兼容单图。

3.2 Dual-DPT：共享空间重组，分别预测深度和射线

DPT（Dense Prediction Transformer）将多层视觉 token 恢复为空间特征，再融合不同尺度信息，输出高分辨率的像素级预测。DA3 的 Dual-DPT 不为两个任务分别建立完全独立的重组网络，而是共享 reassembly（重组模块），随后保留各自的 fusion（融合模块）和输出层。

这使深度和射线从相同的空间布局出发，减少独立解码器对像素位置的不同解释，同时允许深度分支专注局部表面结构、射线分支专注相机相关的方向与原点。需要注意，Figure 2 标注的 Depth 为 N×H×WN\times H\times W，Ray 为 N×H2×W2×6N\times\frac H2\times\frac W2\times6，Points 为 N×H×W×3N\times H\times W\times3。因而实际组合不能直接将不同网格上的数组逐元素相乘，必须先建立深度与射线的空间对应，使每个待反投影的深度值使用其对应位置的射线。论文 §3.1–3.2 未充分说明半分辨率射线如何与全分辨率深度对应，具体重采样或转换实现尚未核实。然而，共享特征不是硬几何约束：如果两个输出预测错误，仍会出现不一致的点云。共享的收益需要通过监督和消融验证。

4. 训练：如何兼顾相机、深度和密集几何细节？

4.1 主模型的联合监督

主模型首先对几何标签进行共同尺度规范。设有效反投影点的范数均值为 ss，当 s>0s>0 时，同时将点、深度和相机平移除以 ss，而保持旋转、内参与射线方向不变，即可维持 𝑷/s=𝒕/s+(D/s)𝒅\mathbf P/s=\mathbf t/s+(D/s)\mathbf d。这帮助不同尺度场景参与训练，但不提供真实米制尺度。

论文 §3.3 的总损失包括深度、射线、点图、相机和深度梯度：

ℒ=ℒD(D̂,D)+ℒM(R̂,M)+ℒP(D̂⊙d+t,P)+βℒC(ĉ,v)+αℒgrad(D̂,D).\mathcal L=\mathcal L_D(\hat D,D)+\mathcal L_M(\hat R,M)+\mathcal L_P(\hat D\odot d+t,P)+\beta\mathcal L_C(\hat c,v)+\alpha\mathcal L_{grad}(\hat D,D).

其中 R̂\hat R 指预测射线图（不是旋转矩阵），MM 为射线标签，PP 为点图，ĉ,v\hat c,v 为相机预测及标签，α=β=1\alpha=\beta=1。点项中的 d,td,t 原文未明确标注预测值或 GT；如果采用预测射线，组合点损失会通过 ∂P/∂D=d\partial P/\partial D=d、∂P/∂d=DI\partial P/\partial d=DI 同时约束两个分支。若用 GT 射线，则不会对射线预测产生该梯度，不能在未核实实现时断定具体路径。

以深度损失为例，其有效像素置信加权形式为

ℒD=1ZΩ∑p∈Ωmp(cp|D̂p−Dp|−λclogcp),\mathcal L_D=\frac{1}{Z_\Omega}\sum_{p\in\Omega}m_p\left(c_p|\hat D_p-D_p|-\lambda_c\log c_p\right),

其中 mpm_p 为有效掩膜、cpc_p 为深度置信度、ZΩZ_\Omega 为归一化因子。第一项使低置信像素的残差影响变小，第二项防止所有置信度简单趋于零。若假定 c>0c>0 无上界、e=|D̂−D|>0e=|\hat D-D|>0，对单点目标求导有 e−λc/c=0e-\lambda_c/c=0，得到 c*=λc/ec^*=\lambda_c/e。这是解释性推导，实际 confidence 参数域未由本文完整说明，不能把它当作已经校准的真实误差概率。

深度梯度损失（Eq. 3）为

ℒgrad=∥∇xD̂−∇xD∥1+∥∇yD̂−∇yD∥1.\mathcal L_{grad}=\|\nabla_x\hat D-\nabla_xD\|_1+\|\nabla_y\hat D-\nabla_yD\|_1.

它要求预测深度边缘与监督一致，不是简单地平滑所有梯度。主模型先使用真实深度标签训练，在 120k 步后切换到教师生成且已对齐的深度标签，总训练 200k 步；相机条件以 0.2 的概率激活。训练使用不同图像分辨率和视图数量，动态调整 batch 以控制 token 数量。由此可见，模型只以 Depth-Ray 作为主要表示，不代表训练只使用两种损失。

4.2 为什么需要合成数据训练的教师？

真实多视角数据的深度往往来自 SfM/MVS 或传感器：弱纹理、遮挡、细结构及采集限制会产生缺失和噪声。直接用这些标签进行逐像素监督，容易缺少边缘和局部细节的可靠信号。论文先用密集的合成深度训练独立单图教师，再将其迁移到真实数据。教师仍采用 DINOv2 与 DPT，但训练目标使用相对深度而非 DA2 的相对 disparity，并引入 exponential depth 以提高近处敏感性；本文没有给出具体指数映射，不应自行补成某个函数。

合成数据也并非天然正确。附录展示了错误天空背景、RGB–depth 空间错位、透明材质、深度裁切和无效海面标签等问题。作者对这些样本进行筛除或深度截断。这里的数据清理是教师监督的前提，而不是模型已经解决透明、反射或复杂介质重建的证据。

教师损失除了梯度与基于 ROE alignment 的全局—局部深度目标外，还有距离加权法向监督。设局部三角面的未归一化法向为 nin_i，其模长等于三角形面积的两倍，可能随跨越深度断层的邻接向量增大。论文 Eq. (4)–(6) 给出

wi=∑j=04∥nj∥−∥ni∥,nm=∑i=04wini∥ni∥,w_i=\sum_{j=0}^{4}\|n_j\|-\|n_i\|,\qquad n_m=\sum_{i=0}^{4}w_i\frac{n_i}{\|n_i\|},

ℒN=ℰ(n̂m,nm)+∑i=04ℰ(n̂i,ni),\mathcal L_N=\mathcal E(\hat n_m,n_m)+\sum_{i=0}^{4}\mathcal E(\hat n_i,n_i),

其中 ℰ\mathcal E 为法向间角误差。大模长法向获得相对更低权重，既监督局部聚合方向，也监督各法向；权重并不是精确的距离度量，模长还取决于夹角。原文描述四个邻点，而公式求和从 0 到 4，具体索引构造需进一步核实。教师最终目标（Eq. 7）为

ℒT=0.5ℒgrad+ℒgl+ℒN+ℒsky+ℒobj.\mathcal L_T=0.5\mathcal L_{grad}+\mathcal L_{gl}+\mathcal L_N+\mathcal L_{sky}+\mathcal L_{obj}.

其中全局—局部项 ℒgl\mathcal L_{gl} 使用 ROE 对齐，本文未展开其内部公式；天空与物体掩膜损失为 MSE，用于处理没有可靠深度标签的区域。

Table 9（PDF p.19）直接检验的是教师自身的训练设计：ViT-L、batch size 64，五个数据集的平均指标。数据从 V2 扩展至 V3、再加入多分辨率训练时，AbsRel 从 0.087 降至 0.079、0.072，δ1\delta_1 从 0.919 升至 0.929、0.938；数据规模与组成并未独立控制。几何目标采用 Depth 时 AbsRel/SqRel 为 0.089/0.637，优于 Disparity（0.095/1.033）和 Pointmap（0.096/0.693），但 Disparity 的 δ1\delta_1 为 0.919，略高于 Depth 的 0.918。SqRel 是以真值归一的平方误差均值。

完整教师损失的 δ1\delta_1/AbsRel/SqRel 为 0.919/0.087/0.596，优于 MAE-Loss 的 0.918/0.089/0.637；相比去掉距离加权法向项的 0.918/0.087/0.600，AbsRel 持平，另两项仅小幅改善。因此完整损失有支持，但不能将较大收益单独归因于法向监督。这三个消融组应各自比较；Table 7(e) 和 Table 11 分别考察教师标签对主几何模型和 metric 模型的作用，不是对教师自身损失的重复消融。

4.3 把教师的相对深度对齐到真实场景

教师擅长预测相对结构，但其输出尺度和零点并不天然符合多视图测量。因此作者在每图的有效真实深度上拟合尺度和平移（Eq. 8）：

(ŝ,b̂)=arg⁡mins>0,b∑p∈Ωmp(sD̃p+b−Dp)2,(\hat s,\hat b)=\arg\min_{s>0,b}\sum_{p\in\Omega}m_p(s\tilde D_p+b-D_p)^2,

DT→M=ŝD̃+b̂.D^{T\to M}=\hat s\tilde D+\hat b.

这里 D̃\tilde D 是教师预测，DD 是原测量；为区分相机平移，将原文标量 shift tt 写为 bb。作者使用 RANSAC 进行鲁棒拟合，以残差相对中位数的平均绝对偏差确定内点阈值。对于固定内点集，将教师值记为 xix_i、真值记为 yiy_i，普通最小二乘的无约束解为

s=∑i(xi−x‾)(yi−y‾)∑i(xi−x‾)2,b=y‾−sx‾.s=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\qquad b=\bar y-s\bar x.

当分母非零且解为正时，这给出了所需的仿射对齐。它保留教师的相对深度顺序和结构，同时借助真实测量校准整体尺度。但是，如果有效锚点集中在相似深度，尺度估计会不稳定；如果教师存在局部非线性形变，全局 scale-shift 也无法修复。未测量区域的伪标签是先验而非独立真值，更清晰的深度不必然对应更小的绝对误差。

4.4 不同模型的训练目标不能混为一谈

  • 主 DA3 联合估计多视角几何和相机，也兼容单图输入。
  • 单目学生在无标签真实图像上使用教师的相对深度伪标签训练，专注单目深度。
  • DA3-metric 专注度量深度，额外采用 canonical focal 规范。若实际焦距为 ff，原文令 fc=300f^c=300，将训练深度变换为 Dc=Dfc/fD^c=D f^c/f。按此标签定义，有焦距时逆变换为 D=Dcf/fcD=D^c f/f^c。该模型以对齐教师标签与真实度量标签混合监督（20% 使用原 GT）。

后两种专门训练模型并不是主 DA3 自动改变输出单位。焦距归一化亦不能在数学上消除单目真实尺度的所有歧义，仍需度量训练标签与学习先验。

5. 从几何基础模型到前馈 3DGS

5.1 Pose-conditioned Gaussian 模型

在已知相机设置下，DA3 将额外 GS-DPT 连接至几何主干，逐像素预测 Gaussian 的 opacity、旋转四元数、尺度和颜色。中心并非作为完全独立的自由三维坐标回归，而由预测深度及相机反投影获得。以常见 Gaussian 表达为背景，若旋转矩阵 RqR_q 对应四元数、尺度为 (sx,sy,sz)(s_x,s_y,s_z)，协方差为

Σ=Rqdiag⁡(sx2,sy2,sz2)RqT.\Sigma=R_q\operatorname{diag}(s_x^2,s_y^2,s_z^2)R_q^T.

目标相机投影并栅格化这些 Gaussian，按深度进行透明度合成（3DGS 通用机制）：

C=∑kTkαkck,Tk=∏j<k(1−αj).C=\sum_k T_k\alpha_k c_k,\qquad T_k=\prod_{j<k}(1-\alpha_j).

训练使用目标视角颜色 MSE、LPIPS，以及源视角的尺度平移不变深度损失。几何监督降低仅靠颜色拟合而使 Gaussian 中心漂离表面的风险。测试时由网络从输入图像前馈预测，不需要对每个新场景重新进行传统 3DGS 的逐场景优化。

5.2 Pose-adaptive 扩展

论文另介绍可接受已知或未知相机的 pose-adaptive 版本：局部相机坐标下预测 Gaussian，已知位姿时利用 Umeyama 缩放对齐预测深度/局部 Gaussian，未知时采用预测相机；通过额外深度 offset 提供渲染自由度，用球谐函数（SH）表示视角相关颜色。训练时冻结预训练几何主干，只训练 GS-DPT。

这一扩展能兼容不同输入条件，但不能把后续已知位姿 NVS 表格的分数直接归给未知位姿版本。深度 offset 和视角相关外观也说明：高斯能渲染合理图像，不必严格对应真实物理表面。

6. 实验：哪些设计得到了支持？

6.1 位姿与几何重建

作者在 HiRoom、ETH3D、DTU、7Scenes 和 ScanNet++ 上同时评价相机及几何。每个场景最多使用 100 张图像，超限时固定种子采样。相机评价先计算图像对的相对旋转与平移方向角误差，在每个角度阈值下统计相应的准确率 RRA（Relative Rotation Accuracy）与 RTA（Relative Translation Accuracy）。论文 §6.2 取每个阈值处两条准确率曲线的较小值构成 accuracy–threshold 曲线，再积分得到 AUC；Auc3 比 Auc30 更关注小角度误差。几何评价使用同一组输入：以 evo 将预测相机位姿对齐到真值坐标系，并通过 RANSAC 随机抽取位姿子集拟合变换，以平移误差小于整体位姿偏差中位数为内点标准，选取内点最多的候选变换。按该变换对齐后，再使用预测深度进行 TSDF（截断符号距离场）融合，评价最终几何；TSDF 将多视图深度观测整合到统一体素场，结果同时受位姿、深度与融合过程影响。DTU 按 §6.3 使用专门的前景去除和默认深度融合策略。除 DTU 使用毫米单位的 Chamfer Distance（CD，越低越好）外，其余使用阈值距离内精度与召回的调和平均 F1（越高越好）。因此指标并不是未经外部对齐的绝对尺度误差。

7. 局限与研究启发

DA3 的关键贡献不是凭空创造新的针孔几何，而是将已有的反投影关系用于预测目标设计，通过标准预训练 Transformer 实现不同图数的几何推断，并利用教师对齐弥补异质标签的不足。实验说明这条组合路线具有较强实用价值，同时保留了几个重要边界：

  1. 观测与先验。 单图、低视差、遮挡或无共视区域仍可能缺少独立几何证据。Figure 9 展示 1、2、13 图的案例，但它们不是固定场景的视图数消融，不能从中量化图数收益。
  2. 相机与尺度。 共享输出不保证每条 ray 都来自同一个合法相机；主模型的尺度归一化、几何评价的相似对齐与专门 metric 模型的目标不能混淆。
  3. 教师可靠性。 仿射对齐可校准整体比例和平移，不能纠正局部形变或系统性缺测。清晰度提升不必然等价于绝对深度准确。
  4. 渲染与几何。 Gaussian 的位置偏移、opacity 与视角相关颜色都允许外观拟合和表面位置之间出现偏差；已知位姿 NVS 的成功不证明未知位姿或真实完整几何恢复。
  5. 泛化与动态。 论文没有提供所有输入数量、退化成像、动态环境和复杂介质下的系统专项验证；作者在结论中也将动态空间推理等留给未来工作。

从独立研究视角，更值得继续考察的是可靠性，而不仅是增加模型容量。固定图数而改变有效共视与视差，可以检验模型何时依赖观测、何时主要依赖先验；固定教师输出而改变深度锚点的空间覆盖，可以检验伪标签对齐何时稳定；固定外观容量而干预 Gaussian 中心，可以检验几何误差在不同目标视点距离下如何影响渲染。这些是由本文机制和实验边界引出的可验证假设，并非论文已完成的实验，也不代表已确认研究空白。

总之，DA3 的价值在于把深度、相机与可见三维结构组织成一个统一的几何推断接口，再以这一接口连接单目估计、多视角重建及前馈渲染。理解其设计优势，需要同时理解表示、监督和观测条件，而不能只关注最终 benchmark 数字。
